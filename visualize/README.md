# Sendov's Conjecture — Interactive Visualization

An interactive visualization of [Sendov's conjecture](https://en.wikipedia.org/wiki/Sendov%27s_conjecture):

> If all roots of a polynomial lie in the closed unit disk, then every root has a critical point (zero of the derivative) within distance 1.

**▶ Open it here: <https://doufuchuan.github.io/visualize/>**

Drag the blue root dots (constrained to the unit disk). The red dots are critical points, computed in real time in your browser with the [Aberth method](https://en.wikipedia.org/wiki/Aberth_method). Each light-blue circle has radius 1 — if any root ever ends up with no critical point inside its circle, you've found a counterexample (nobody has in 60+ years).

Single self-contained HTML file, no dependencies, works offline.

See also the companion article (in Chinese) about the conjecture and its 2025 proof by Bartłomiej Mazur.
